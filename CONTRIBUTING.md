# Contributing to AI Skills

Thank you for your interest in contributing to the **AI Engineering Skills Library** (`ai-skills`).

## 📋 Guidelines

1. **Follow the Skill Specification**: Refer to [`docs/skill-format.md`](docs/skill-format.md) for the required YAML frontmatter and document structure.
2. **Focus on Production Trade-offs**: Every skill must detail real-world tradeoffs (token budget, latency penalty, maintenance cost).
3. **API Versioning**: Specify target library versions to prevent drift.
4. **Git Hygiene**: Commits must follow Conventional Commits (`feat(domain): description` or `fix(domain): description`).

## 🛠️ Submission Process

1. Fork the repository.
2. Create a feature branch (`feat/new-skill-name`).
3. Ensure markdown files validate cleanly.
4. Submit a Pull Request targeting `main`.
